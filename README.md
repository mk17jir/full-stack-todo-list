## Features

- User registration and login
- JWT authentication
- Create, edit, delete todos
- Mark todos completed
- Pin important todos
- Search todos
- Todo priority levels
- Due dates
- Responsive UI
- Dark mode support

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router
- React Hot Toast

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
